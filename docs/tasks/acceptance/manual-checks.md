## 三、建议抽查顺序

按风险从高到低，前 5 条涉及资金与权限，后 5 条是内容展示与发布配置。

| 顺序 | 编号 | 理由 |
| ---: | :--- | :--- |
| 1 | F6-3 | 完整 Key 一旦在详情页复现就是凭据泄露；先确认明文只出现一次 |
| 2 | F6-6 | 分组决定计费倍率；只读入口失守会让用户自行改分组 |
| 3 | F2-2 | 对外定价表直接构成报价依据；缺「积分」列会影响用户对赠送额的判断 |
| 4 | F8-3 | 缓存价误展示会形成错误价格预期；徽标无自动化断言，只能目视 |
| 5 | OI-05 | 提额、发票、退款通知缺失会让资金状态变化不可见 |
| 6 | F1-6 | 仅目录模型对外可见会形成「可售」误解 |
| 7 | F1-4 | 接入点出现「可用」属于对外可用性暗示，与 §9.2 不承诺可用性的口径冲突 |
| 8 | F3-3 | 示例值若被当成真实 Key 使用，会暴露文档错误 |
| 9 | OI-12 | 发布配置错误会让用户复制的示例域名调不通 |
| 10 | OI-11 | 布局缺陷影响观感，不影响资金与权限 |
