## 1. 目标

交付运营的 8 个工作面。判断标准：**一个运营在不看技术文档的前提下，能完成"加一条渠道 → 配一个模型与价格 → 上架 → 发公告 → 处理一张单据"**，且每条会踩坑的校验都在保存前就给出可读的原因。

## 4. 硬约束（违反即驳回）

1. **来源地选「境外」→ 前端即拦截并说明原因**（后端也拦，双保险）。不得只保存后再报错。
2. **上游 Key 输入框**：编辑时只显示掩码 + 「重新填写」按钮；**不得**把明文回填到表单 value（DOM 会暴露）。
3. **毛利地板提示必须给出差额**：不满足时显示「当前毛利率 x%，地板 25%，差额 y 积分/千 token」，而不是只说"校验失败"。
4. **公示期**：涨价生效时间选择器**最小可选值为今天 +7 天**；降价可即时。前端限制 + 后端校验双重。
5. **唯一真相源冲突提示**：同模型两处配价时，明确指出两份来源（页面 + 行标识），并提供「跳转到另一处」入口。
6. **审核中心默认 `PENDING` 且按提交时间升序**；不得按"重要程度"重排。
7. **驳回必须填理由**：前端 required + 最少字数（建议 5 字），后端再校验。
8. **自审禁用**：若 `submitter == 当前登录人`，通过/驳回按钮置灰并给出原因；后端仍会拒绝（不能只靠前端）。
9. **工单 SLA 只提示不处置**：超 4h 显示红色倒计时/超时标记，**不得**提供"自动关闭"开关。
10. **模型上架/下架必生成公告草稿**并在保存后提示「已生成待发布公告」。
11. **`internal` 分组必须显示「不计费」**而不是「免费/0 折」；倍率 0 不是折扣。
12. **配置中心（若有入口）只显示 12 个白名单键**；其余键只读展示并标注"需发版"。
13. **所有写操作成功后必须刷新审计记录**（页面可查变更前后值）。
14. **不得在后台页面展示上游 Key 明文、用户密码、完整 API Key**。
15. **运营后台不得出现"代理管理""提现"菜单**（V2.0 范围）。
