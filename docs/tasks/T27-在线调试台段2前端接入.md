## 5. UI 具体改动（6 项，逐项做到）

1. **Key 选择器**：用 `useKeys({ page: 1, pageSize: 50 })`（参数按现有签名）列出本人 Key，只显示 `name` + `mask`。默认选第一个 `ENABLED` 的 Key；无可用 Key 时发送按钮禁用并提示「请先在密钥管理页创建密钥」，附链接 `/console/keys`。
2. **发送接线**：`key_id` + 现有 `preview` 构造的 `body`（注意 `preview` 是**字符串**用于展示，发送时必须传对象，不要 `JSON.parse(preview)` 后再发，直接复用同一份构造逻辑抽成函数）。
3. **流式渲染**：`stream=true` 时把 delta 追加到当前 assistant 消息，带打字光标（`▍` 或等效，CSS 闪烁即可）；`stream=false` 时一次性渲染。渲染中禁用发送按钮，支持「停止」（`AbortController.abort()`，中止后保留已收到的内容并标注「已中止」）。
4. **消耗与余额**：每次调用后读 `X-Credits-Remaining` 更新页面余额显示；同时在成功后 `invalidateQueries` 刷新 overview，保证与其它页面一致。若响应无该头（非 402 的异常路径），显示「本次消耗以用量页为准」而不是编一个数字。
5. **余额不足拦截（F12-3）**：`insufficient`（`balance.micro <= 0`）为真时不发请求，直接提示并给「去充值」链接 `/console/recharge`；后端返回 `insufficient_credits`（402）时同样处理，且用响应头的 `X-Credits-Remaining` 刷新余额。
6. **代码生成**：新增一块「调用代码」，Tab 或 Select 切 `curl` / `Python` / `Node`，内容由当前 model + messages + 参数生成，**使用用户已选 Key 的 mask 占位**（如 `sk-****abcd`），绝不渲染任何完整 Key。复制按钮复用既有 `CopyBlock`。

## 6. 硬约束（违反即打回）

1. **禁止使用 `EventSource`**。端点要求 `POST` + 会话 Cookie + CSRF 双提交头，`EventSource` 只能 GET 且不能带头。必须用 `fetch` + `ReadableStream`。
2. **SSE 解析必须能处理跨 chunk 的半帧**。一条事件被网络切成两段是常态；把每块直接 `split('\n\n')` 解析会丢字。必须保留残尾到下一块。这是本卡最容易写错的地方，`sseStream.test.ts` 的「一帧跨三 chunk」用例必须存在。
3. **`TextDecoder` 必须带 `{ stream: true }`**，否则 UTF-8 多字节字符被切断会产生乱码（中文场景必现）。
4. **不得渲染任何完整 Key**。代码生成里只用 mask；`grep` 审计时不得出现拼接完整 key 的代码路径。
5. **不得自行扣费或在浏览器算余额**。余额只来自 `X-Credits-Remaining` 或 overview 接口；禁止用「调用前余额 − 估算消耗」之类的本地计算。
6. **`body` 不得被前端篡改**：`key_id` 只能出现在外层，不能塞进 `body`；不得添加后端未定义字段。
7. **必须实现中止**：组件卸载或用户点「停止」时 `abort()`，避免流挂住持续占连接（gatewayd 侧预扣在 P14 才结算，挂死会拖长占用）。
8. **不得改后端**。`web/` 之外一个文件都不碰（`docs/tasks/T27-*.md` 的 §11 也不碰）。
9. **既有降级文案必须移除**，包括「发送（调试台需要后端代理端点，待实现）」「未接入执行链路」「页面不会发送」三处，以及 `Badge variant="warning"`。留一句「调试台调用走真实扣费」的提示即可。
