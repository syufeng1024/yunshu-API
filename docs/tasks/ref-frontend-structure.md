## 2. 可选借鉴（做了更好，不做不影响验收）

以下四项是参考站里**我们能用、且不违反 PRD** 的做法。全部属「有则加分」，实现方自行判断是否值得做。

| 借鉴点 | 具体做法 | 为什么值得 | 落点 |
| :--- | :--- | :--- | :--- |
| ① Hero 用三短句承载价值 | 把一句长副标题拆成三行短句（如「主流模型 / 换地址即用 / 按量计费」） | 扫读成本低，且不涉及数值承诺 | 首页 Hero |
| ② 工具入口提前 | PRD §4.1 把「工具集成入口」排在接入点之后；参考站放在第二屏 | 用户最先问的是"我的工具能不能用" | 首页，可选前置 |
| ③ 核心能力用「左标题 + 右编号条目」 | 左列 4/12 吸附标题，右列 8/12 放 01–06 条目 | 比 6 张等宽卡片更容易读完 | 首页核心能力区（内容仍是 PRD 的六项） |
| ④ 首页尾部放「快速接入三步 + 代码块」 | 注册 → 创建令牌 → 填 Base URL，配按工具切的示例 | 把转化到"第一次成功请求"的距离缩短 | 首页底部 CTA 之前，可选 |

**若采纳 ② / ④ 导致与 PRD §4.1 表内顺序不一致**：属展示取舍，验收不看顺序；但**区块内容一条都不能少**。若拿不准，就按 PRD 顺序写。

## 3. 版式约定（可参考，非强制）

| 模式 | 做法 | 适用 |
| :--- | :--- | :--- |
| 三段式区块头 | 小标签（如 `WHY YUNSHU`）→ H2 → 一句副标题 | 首页各区块、后台概览 |
| 编号条目 | `01` 浅色大号数字 + 加粗小标题 + 两行说明 | 能力、步骤 |
| 表格优先 | 价格/套餐差异一律表格 | 价格表、套餐表、用量账单 |
| 按工具切 tab 的代码块 | tab + 文件路径标签 + 复制按钮 | 快速接入、文档第 9 章 |
| 工具墙 | 静态展示，5 个工具即可 | 首页工具入口 |

**关于走马灯**：参考站用「重复成员填充」制造密度。我们只有 5 个工具（F4-1），重复填充会暗示支持更多，**不建议**采用；静态 5 卡即可。

## 4. 不采纳清单（**这是禁写项，不是建议**）

| 参考站元素 | 为什么不采纳 | 依据 |
| :--- | :--- | :--- |
| 「注册即送 5 元测试金」 | 我方是**主动领取** 10 万积分（7 天体验版），不是注册自动送现金 | PRD §4.2、`trial_claimed_at` 主动领取 |
| 「官方价 1–7 折」等折扣话术 | V1.0 不做引流分组，官网只显示 `standard` 单价 | F1-5、PRD §3.5、附录 C.2 |
| 合规资质区块 | 证照到位前**不展示**，避免空链 | PRD §2.1 备注、§4.1 页脚 |
| 调用排行（近 24h 热度） | 需对外披露真实调用量与占比，口径未定；V1.0 不做对外指标披露 | 登记 Q-05（V2 候选） |
| 配置助手（Windows 客户端） | V1.0 不做客户端分发；等价能力是 `/integrations` 一键导入 | F4-1–F4-3 |
| 12+ 工具 logo 墙 | 只承诺 5 个工具，多列即暗示支持更多 | F4-1 |
| 多模态效果示例（生图/视频） | V1.0 对外只有文本与图像生成；视频无端点 | PRD §4.3 第 5 章、§3.4 |

| 首页 FAQ 区块 | 计费 Q&A PRD 已要求放**定价页**，首页复述会造成文案漂移 | PRD §4.2、F4-5 口径 |

## 5. 红线（照抄参考站会直接违反，务必逐条排除）

1. 首页价格/额度必须是**表格 + 后台数据**，不得出现「1 折起」「低至」类话术。
2. 任何区块不得出现：`送…元`、`折`（折扣义）、`代理`、`加盟`、`许可证编号`。
3. 工具相关只允许 Cursor / Claude Code / Cherry Studio / NextChat / OpenAI SDK 五个名称；不写「更多工具」「即将支持」。
4. 接入点区块只写线路与 Base URL；**无健康检查数据就不写「可用/正常/在线」**。
5. 示例代码的域名、Key、request_id 全为虚拟值，页首须有「示例为虚拟值」声明。
6. 模型列表只出现 `LISTED`；`CATALOG_ONLY` 不得进任何对外区块。
7. 定价页 FAQ 与文档页第 6/7 章共用同一内容源，不得两处各写一份。
