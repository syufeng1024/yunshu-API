## 1. 目标

把 TDS 的 31 阶段流水线的前半段（**接入 → 鉴权 → 授权 → 幂等 → 选路 → 预估 → 限流 → 预扣**）实装为可运行服务。本卡结束时，`POST /v1/chat/completions` 能在**不调上游**的前提下走完全部前置判定并正确返回 400/401/402/403/429/503。上游调用（P15+）属 T08。

## 4. 硬约束（违反即驳回）

1. **执行顺序必须是 `P05 → P08.5 → P12 → P09 → P11 → P10`**，不是编号顺序。TDS §3.1 已裁定：日额度需要 `est_micro`，而 `est_micro` 需要先选出路由。代码里要有注释说明这一点，且 `pipeline_test` 断言实际调用顺序。
2. **P07 五步顺序不可调换**：可售性（`listing_state`）→ Key 授权 → 分组范围。理由：先报用户能自己改的，再报改不了的。
3. **`CATALOG_ONLY` 返回 503 `model_not_available`**，`DELISTED` 返回 400 `model_not_found`（对外等同不存在）。
4. **`/v1/models` 不消耗额度**：不预扣、不限流；返回 `授权 ∩ LISTED ∩ region=DOMESTIC ∩ 分组范围`，`CATALOG_ONLY` 不出现。
5. **网关不得读主库常规查询**：除 `gw_write_dsn`（8 连接、单事务 200ms、`ConnMaxLifetime=5min`）外无 DB 访问；鉴权缓存未命中即 401，**无回落**。
6. **禁止 `context.Background()`** 出现在请求路径；任何 I/O 必须继承 P01 建立的 `ctx`。
7. **超时预算**：P02 5s、P05 8ms（Redis 单次 HGETALL）、P10 50ms、P11 8ms（P99 25ms）、P12 5ms、P16 30s；总预算非流式 120s / 流式 600s，**重试不追加预算**。
8. **背压阈值是单实例占比**（60%/90%），`gw.max_inflight` 是进程级，集群容量 = 值 × 副本数。**不得**写成集群语义。
9. **背压与限流码不同**：全局闸门拒绝 → `503 backpressure_*`；per-Key 并发超限 → `429 concurrency_limit_exceeded`。**不得混用**。
10. **P10 超时处置**：返回 503 + 释放连接与租约，但**预扣保持 HELD 不释放资金**（无法判断事务是否已提交），交 T09 的悬挂对账兜底。
11. **选路必须过滤境外**：`region='OVERSEAS'` 的渠道与模型即使被误配入库也**不得被选中**（PRD §3.4）。这是硬过滤，不是优先级。
12. **专属渠道过滤**：`dedicated_scope_mode=SELECTED` 的渠道只对 `t_channel_dedicated_user` 内用户可见；非名单用户候选集不含该渠道。
13. **权重随机用快照内权重**，`sum(weight)=0` 时按均等权重并从日志 WARN。
14. **幂等 `Idempotency-Key` 不强制**：缺失即跳过 P08；`idem.duplicate_window=10s`。
15. **所有响应必须带 `X-Request-Id`**，且与体内 `request_id` 同值。
16. **不得在 P04 做业务授权**（模型是否存在/可售在 P07），也不得在 P07 做参数校验（在 P04）。
17. **监听地址不得写死**：网关端口一律取 `cfg.GatewayAddr`（`GATEWAY_HTTP_ADDR`，默认 `:8080`），metrics 取 `cfg.MetricsAddr`。本机 8080 被其他容器占用、`.env` 已设为 `:8082`；写死会导致本卡直接跑不起来。同理，任何超时/上限不得写死数值——应来自 T05 的配置快照（`gw.*` 键）。

## 5. 验收标准

| # | 判定 | 方式 |
| :--- | :--- | :--- |
| A1 | `go test ./internal/gw/... -race` 全绿 | 复跑 |

| A3 | 无 Key → 401 `invalid_api_key`；过期 Key → 401 `key_expired`（**两个不同码**） | 单测 |
| A4 | `CATALOG_ONLY` 模型 → 503 `model_not_available`；`DELISTED` → 400 `model_not_found` | 单测 |
| A5 | 未授权模型 → 403 `model_not_authorized`；分组不含 → 403 `model_not_in_group`（**顺序：先授权后分组**） | 单测 |
| A6 | 同时带 `Authorization` 与不同的 `x-api-key` → 400 `conflicting_auth_headers` | 单测 |
| A7 | 余额不足：`raw_est=6000`、余额 `5000` → 402；余额 `6500` → 放行（**G-02 别在网关层被破坏**） | 单测 |
| A8 | RPM 触顶 → 429 `rpm_limit_exceeded` 且 `Retry-After` 与 `reset_at` 一致 | 单测 |
| A9 | 背压 90% → 503 `backpressure_rejected`；流式 → `backpressure_stream_rejected` | 单测 |
| A10 | 选路：混入 1 条境外渠道 + 1 条专属渠道（非名单用户）→ 候选集均不含 | 单测 |
| A11 | 权重：A=90 / B=10，10 万次抽样 A 占比 0.90±0.01 | 单测 |
| A12 | 体积：11 MB 体 → 413 `request_too_large`；体读超 5s → 408 | 单测 |
| A13 | `grep -rn "context.Background()" internal/gw` 为空 | grep |
