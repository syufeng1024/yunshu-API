## 1. 目标

建立「三进程、一共用 module」的可编译、可启动、可观测骨架：`gatewayd` / `controld` / `jobsd` 三个二进制能各自起来并正确回答健康检查，本地 `docker compose` 一键拉起 MySQL 8.0 + Redis 7，工程约定（目录、错误、JSON、日志、环境变量）在此一次性定死，后续 22 张卡不再讨论。

## 5. 硬约束（违反即驳回）

1. **三进程一 module**：`cmd/{gatewayd,controld,jobsd}` 共用同一 `internal/`，不得拆成三个 module（`relaykit` 除外，见 T08）。
2. **`gatewayd` 不持常规主库连接池**：只允许一条受限通道 `GATEWAY_DB_MAX_CONNS`（默认 8）、`ConnMaxLifetime=5min`、单事务 `200ms` 超时。T01 只建连接与超时常量，**不建立任何业务查询**。
3. **`/healthz` 不得探测 Redis / MySQL**：只反映进程自身。`/readyz` 才探测依赖，任一不健康返回 `503` 且体为 `{"status":"not_ready","checks":{...}}`。
4. **优雅停机**：收到 `SIGTERM` 后停止接收新连接，等在途请求至 `drain_deadline`（默认 `120s`），超时强制退出并记 WARN 日志。
5. **日志**：JSON 行格式；时间字段 RFC3339Nano **UTC**；固定字段集 `ts,level,svc,env,pid,trace_id,request_id,uid,kid,model,stage,latency_ms,status,msg`；未取到的字段置空而**不省略键**（便于日志库建列）。
6. **禁止日志输出敏感值**：上游渠道 Key、用户 API Key 明文、密码、`Authorization` 头一律不可入日志；Key 只能出现 `sha256` 前 16 位。
7. **时间**：进程内统一 UTC，时区仅在展示层按 `Asia/Shanghai` 转换。
8. **JSON**：业务代码 `import "encoding/json"` 只允许出现在 `internal/jsonx`，用 `grep -rn '"encoding/json"' --include=*.go | grep -v internal/jsonx` 校验为空。
9. **环境变量命名**：`DB_DSN`、`LOG_SQL_DSN`、`GW_WRITE_DSN`、`REDIS_ADDR`、`REDIS_PASSWORD`、`GATEWAY_METRICS_ADDR`、`GATEWAY_METRICS_TOKEN`、`GATEWAY_DB_MAX_CONNS`、`SESSION_SECRET`、`ENV`。缺失必填项一次性列出全部并 `exit 1`。
10. **许可**：new-api **允许二次开发**，**参考其代码写法或架构不需要署名**（不需要保留其 Section 7 notice，也不需要加原项目链接）。但**不得把其源码 / SQL / Lua / 配置片段并入本项目** —— 本项目商业闭源，并入即构成衍生作品、须整体 AGPL，与闭源冲突。落地为代码级门禁：`internal/`、`cmd/`、`relaykit/` 的 `.go`/`.sql` 不得出现 `QuantumNous`（`scripts/lint.sh` 第 7 条）；**文档与注释里可以正常引用其项目名与链接**。产品界面**不得**添加其 notice 或「基于 new-api」表述（未使用其代码，加了是错误来源声明）。见 errata E-23。
11. **`context.Background()`** 只允许出现在 `main` 与后台任务根 goroutine；请求路径不得使用（`grep -rn "context.Background()" internal/ cmd/` 逐条说明）。

## 6. 验收标准

| # | 判定 | 判定方式 |
| :--- | :--- | :--- |
| A1 | `go build ./...` 与 `go vet ./...` 零错误 | 复跑命令 |
| A2 | `make up` 后 `docker compose ps` 两服务均 `healthy` | 复跑命令 |
| A3 | `docker exec` 进 MySQL 执行 `SHOW VARIABLES LIKE 'collation_database'` 返回 `utf8mb4_0900_as_cs` | 复跑命令 |
| A4 | 三进程分别 `go run ./cmd/xxx` 后 `curl -s localhost:PORT/healthz` 返回 `{"status":"ok"}` | 复跑命令 |
| A5 | 停掉 Redis 后 `/healthz` 仍 200、`/readyz` 返回 503 且 `checks.redis == "down"` | 复跑命令 |
| A6 | `SIGTERM` 后进程在 120s 内退出，日志含 `drain` 字样且 `exit=0` | 人工 + 日志 |
| A7 | 日志为单行 JSON，含 §5 全部固定键，时间为 UTC | 抽样 3 条 |
| A8 | `grep` 硬约束 §8 / §10 / §11 三条均为空或已逐条说明 | 复跑 grep |
| A9 | `internal/obs/log` 与 `env` 各有单测，`go test ./...` 通过 | 复跑命令 |
| A10 | 缺失必填环境变量时启动失败，输出**一次性列出全部**缺失项 | 删一项后启动验证 |

