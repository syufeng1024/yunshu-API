## 1. 目标

T19 控制台与 T20 运营后台交付时，前端对 **16 处后端缺失**做了「不造假」显式降级（显示"运营侧暂未提供"、按钮置灰、拒调越权接口）。本卡把这些缺口补上，并把前端降级替换为真实能力。

判断标准：**T20 卡 §9.5 的 12 条偏离里，凡属"后端没有"的，全部消失**；前端不再出现"暂未提供/需 T24"的占位文案。

## 3. 硬约束（违反即驳回）

1. **不得直接改余额/账本列**：一切资金变动经 `internal/ledger` 的分录 API；写不到就补方法，不允许 `UPDATE t_user SET balance_micro`。
2. **不得用 0 冒充"无数据"**：成功率、平均值类字段分母为 0 时返回 `null`，前端渲染 `—`。
3. **新接口必须声明权限点**：复用 `internal/control/mw/authz.go` 现有权限，不新增角色；`overview` 用 `admin.read`，`tickets/{id}` 用 `ticket.reply`，`balance-adjust` 用 `user.write`。
4. **每个写接口必须写审计**（`t_admin_audit_log`，含 before/after），且 `target_type`/`target_id` 必须能被新加的过滤条件命中——否则硬约束 5 的过滤等于白加。
5. **契约同步三处**：`internal/control/server.go` 路由表 → `api/openapi.yaml` → `docs/control-api.md`。漏一处即驳回。
6. **`openapi.yaml` 改完必须 `npm run gen:api` 重生成 `web/src/api/types.ts`**，并确认 diff 只含本次新增。
7. **不得改前端既有行为语义**：只允许把"暂未提供/disabled"替换为真实调用；分页、排序、校验文案不动。
8. **SQL 不得全表扫描**：新增查询先 `EXPLAIN`，命中现有索引；确需新索引时在 `deploy/mysql/` 加迁移（编号接着现有最大号，UP/DOWN 成对）。
9. **`-race` 与真实依赖**：go 测试沿用各包 `testmain_test.go` 的真实 MySQL/Redis；不 mock 存储层。

### 7.1 本卡唯一合法的后端验证方式（已实测通过）

Git Bash 下必须先 `export PATH` 再 `MSYS_NO_PATHCONV=1`，否则 `/src` 会被 MSYS 改写成 Windows 路径而报 `working directory is invalid`。

```bash
export PATH="/c/Users/EDY/AppData/Local/Programs/DockerDesktop/resources/bin:$PATH"
export MSYS_NO_PATHCONV=1
GO_IMG=golang:1.27-alpine
DSN='root:root@tcp(host.docker.internal:13306)/yunshu_test?parseTime=true&loc=UTC&charset=utf8mb4'

# 编译（实测 OK）
docker run --rm -v "D:/codes/yunshu-api:/src" -v yunshu-gomod:/go/pkg/mod -w /src \
  $GO_IMG sh -c "go build ./..."

# vet
docker run --rm -v "D:/codes/yunshu-api:/src" -v yunshu-gomod:/go/pkg/mod -w /src \
  $GO_IMG sh -c "go vet ./..."

# 依赖真实 MySQL 的测试（实测 ok 0.678s；**必须同时给 TEST_REDIS_ADDR**，
# 否则容器内会连 127.0.0.1:16379 失败——这是交付总监首版命令的漏项）
docker run --rm -v "D:/codes/yunshu-api:/src" -v yunshu-gomod:/go/pkg/mod -w /src \
  -e TEST_DB_DSN="$DSN" \
  -e TEST_REDIS_ADDR="host.docker.internal:16379" \
  $GO_IMG sh -c "go test -count=1 -p 2 ./internal/control/..."

# gofmt（容器内自带）
docker run --rm -v "D:/codes/yunshu-api:/src" -w /src $GO_IMG \
  sh -c "gofmt -l internal/ cmd/ | grep -v '^\$' || echo OK"
```

**两条限制**：

1. `golang:1.27-alpine` 无 gcc，**`-race` 跑不了**（报 `-race requires cgo`）。`-race` 仍由 CI 的 ubuntu runner 负责，本卡不得声称"已过 -race"。
2. 测试库名用 `yunshu_test`（各包 `testmain_test.go` 会自建/迁移自己的 schema）；不要指向 `yunshu`，会污染开发库。
