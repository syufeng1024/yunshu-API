## 3. 环境事实（已核查，影响交付）

> **勘误（2026-10-26 交付总监，派单后修正）**
>
> 下表第 1 行原写「`assets/logo/svg/` 下只有 `favicon.svg`，其余 5 个 SVG 均缺失」——**该判断错误**。
> 成因：首次盘点用了 `ls -R logo | head -40`，输出在第 40 行被截断，`svg/` 目录恰好落在截断之后，于是只看到了 `favicon.svg`。
> 实测（`git log -1 -- assets/logo/svg/`）：7 个文件在初始提交 `8facf7d` 中即已存在。
>
> **修正后的实际要求**：不是"从零补 5 个 SVG"，而是 **6 个 SVG 逐一对照 PRD §1.4.2 与 `png/` 位图核验，偏差者修正几何，并同步到 `web/public/`**。
> 实现方已发现并纠正此误判，修正了 3 个文件的几何（`mark-elevated` 画布 40→48、`lockup-{light,dark}` 100×28→118×44），A12 按修正后的口径验收。
>
> 附带一条同类教训：本卡的「环境事实」属于**派单前的断言**，一旦与实测不符，应当场报回而不是迁就卡片执行——实现方这次做对了，记一次正向。

## 5. 硬约束（违反即驳回）

1. **技术栈**：Vite + React 18 + TypeScript(strict) + Tailwind；**不引 MUI / AntD / Arco**（D-04）。图表用 Recharts。状态管理用 React Query + Zustand（按需，勿引 Redux）。
2. **品牌名规范**：`云枢 API`（半角空格，API 全大写）。**禁用** `云枢API` / `云枢api` / `云枢_API` / `云枢 API 中转站`（后者是产品描述）。CI 扫描字符串。
3. **`document.title` 品牌段**必须是「云枢 API」，与描述用 `·` 分隔（不用 `-` 或 `|`）。
4. **Logo 必须自托管**，禁止 CDN/图床外链；页脚 Logo 必须**横向**（原型缺陷：`.site-foot a{display:block}` 导致堆叠，勿照抄）。
5. **`<head>` 四声明缺一不可**；`theme-color` 取 `#4F46E5`。
6. **前端 bundle 禁止出现价格与额度字面量**：单价、套餐价、RPM/TPM/并发/日额度一律来自 API。构建后 `grep -rE "[0-9]+ ?积分|[0-9]+ ?元" web/dist/assets/*.js` 只允许命中 i18n 文案模板（如「元」单位后缀），不得命中具体数值。
7. **三端布局互不复用侧栏**：官网用 Header/Footer，控制台与后台用深色侧栏；**不得**出现「用户视角/运营视角」切换器。
8. **权限只做体验层**：前端隐藏菜单只是 UX；每个页面加载时必须调后端校验，403 时显示无权限页而非空白。
9. **错误不伪装成功**：接口失败必须显示错误态（含 `hint`），**不得**渲染空表格或 0 值冒充数据（PRD F5-2 明确要求"断网时图表报错而非显示假数据"）。
10. **格式化单一来源**：积分↔元换算只在 `lib/format.ts`；`grep -rn "/ 100" web/src/pages` 为空。
11. **响应类型由 OpenAPI 生成**，不得手写；后端改契约后 `npm run gen:api` 重生成。
12. **无 UI 框架的隐式主题**：颜色只允许用 token（`--primary` 等）或 Tailwind theme 中的语义色；`grep -rn "#[0-9a-fA-F]\{6\}" web/src` 只允许出现在 `tokens.css` 与 Logo SVG。
13. **可访问性基线**：所有交互元素可键盘聚焦；Logo 链接带 `aria-label`；Modal 有焦点陷阱与 `Esc` 关闭。
14. **首屏体积**：`web/dist` 主 chunk gzip < 300 KB（Recharts 按需引入，路由级 code splitting）。
