## 1. 事实（已核，勿重复调查）

| 事实 | 证据 |
| :--- | :--- |
| PRD 要求：未带键时默认做「10 秒内完全相同请求」去重，**默认开启**、可配置关闭，关闭须在用户协议明示 | PRD `:1993`（D-3 裁定）、`:2007` |

| 对外码语义：409 `conflict_error`、可重试=1、按时长、业务责任、hint「等待首次请求的结果，勿重复提交」 | PRD E.1.6 `:1897` |

## 3. 范围（按 A）

| # | 内容 |
| :--- | :--- |
| 1 | `internal/config/key.go`：确认 `idem.duplicate_window_seconds` 是否在「运行时 12 个可写键」内；若不在，写明只能随发布变更（不得为它单独开后门） |
| 2 | `internal/gw/p08_idem.go`：`Idempotency-Key` 为空时——窗口为 0 或负 → 维持现状（整段跳过）；否则合成键并走 `Begin` |
| 3 | 合成键：`scope` 用**独立值**（如 `gateway-auto`，不得与 `gateway` 混用，否则真实幂等键与自动键在同一命名空间互相污染）；`idem_key` 形如 `auto:<hex>` 且 ≤128 字符 |
| 4 | 结果映射（**与显式幂等键不同**）：<br>· 非流式 + 已有缓存体 → 200 + 缓存体 + `X-Idempotent-Replay: true`<br>· 流式 + 命中 → 409 `duplicate_request_in_flight`（`retry_after_seconds` 取窗口剩余秒数，至少 1）<br>· 在途（`ActionWait`）→ 409 `duplicate_request_in_flight`<br>· 键复用（`ActionKeyReused`）→ 理论上不可达（body 在键里），若出现按 `internal_error` 处理并 WARN |
| 5 | `internal/gw/server.go` 的 `writeReplay`：`duplicate_request_in_flight` 走 409 分支，并补 `X-Idempotent-Replay: true`（仅自动去重路径） |
| 6 | 日志/指标：命中时打一行结构化日志（`idem_auto_dedup` + 是否流式 + 是否返回缓存体）；**不得**记录 body 内容 |
| 7 | 单测（至少 6 条）：① 两次相同非流式请求 → 第二次 200 + 缓存体 + 头，且**只结算一次**；② 两次相同流式请求 → 第二次 409 `duplicate_request_in_flight`；③ 在途重复 → 409；④ 窗口外（同 body、跨窗口）→ 两次都执行；⑤ 不同 body / 不同 model **不得**互相去重；⑥ 窗口配 0 → 行为与现在一致（整段跳过） |

## 4. 硬约束

1. **不得**改动显式幂等键（带 `Idempotency-Key`）的任何行为；两套 scope 必须隔离。
2. **不得**重复计费：命中重放时管道必须在 P09 预扣**之前**停止（沿用 `ErrPipelineStop` + `c.Replay`）。
3. `floor(now / window)` 的取整必须与 PRD 一致（不是滚动窗口）；窗口边界附近允许「跨桶不去重」，**不得**为此引入滑动窗口。
4. 关闭能力必须存在（窗口配 0 即关闭），默认值保持 10。
5. 不改表结构；`idem_key` 超 128 字符必须被截断或换更短编码（建议 hex 截断到 96 字符 + `auto:` 前缀，并在注释里写清为什么不影响唯一性）。
6. 不 commit / 不 push。

## 5. 验收口径

| # | 查什么 | 通过标准 |
| :--- | :--- | :--- |
| 1 | 非流式重放 | 第二次请求 200、body 与第一次逐字节相同、带 `X-Idempotent-Replay: true`、**账本只有一笔扣费** |
| 2 | 流式 409 | 第二次 409 + `duplicate_request_in_flight` + `Retry-After` |
| 3 | 隔离 | 带 `Idempotency-Key` 的请求行为零变化（既有幂等用例全绿） |
| 4 | 反证 | 把窗口硬编码成 0 → 去重用例必须红；把 scope 改回 `gateway` → 隔离用例必须红 |
| 5 | 回归 | `internal/gw`、`internal/idemstore` 全绿（含 `-race`）；`go build`/`go vet` 干净 |
